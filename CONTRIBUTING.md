# Contributing

Obrigado pelo interesse em contribuir com o RevLabs.

## Antes de abrir um PR

1. Abra uma issue descrevendo o problema ou a proposta.
2. Espere a issue ser marcada como `status/ready`.
3. Crie um branch a partir de `main`.
4. Rode os testes e o lint do repositório.
5. Abra um PR usando o template.

## Regras

- PRs de terceiros exigem aprovação do mantenedor.
- Todo PR precisa passar nos checks de CI e no CLA.
- Não inclua assets de jogos (GT7, Assetto Corsa etc.) no repositório.
- Não commite arquivos internos de desenvolvimento (`AGENTS.md`, `.opencode/`,
  `CONTEXT_PROMPT.md`, planos locais).
- Mudanças de schema devem ser feitas primeiro em `revlabs-schema` e depois
  propagadas para os consumidores.

## Licença das contribuições

Ao enviar um PR, você concorda com o [CLA](CLA.md). Você mantém o copyright da
sua contribuição e concede ao mantenedor uma licença perpétua, mundial, não
exclusiva, gratuita, irrevogável, sublicenciável e com direito de relicenciar.

## Código de conduta

Seja direto, técnico e respeitoso. Discussões técnicas são bem-vindas;
ataques pessoais não.
